# 奥术研习助手

## 安装

1. 适用于 Windows 64 位上的 GT New Horizons 2.9.0（Minecraft 1.7.10）。先退出游戏。
2. 从 [Releases](../../releases/latest) 下载 `ArcaneResearchAssistant.jar`，放进当前整合包的 `mods` 文件夹。
3. 如果装过旧版，先移出旧的 `TCAutoResearch.jar`，再启动游戏。

## 用法

1. 打开神秘时代的研究台，切换「背包」「无扭曲」或「扭曲」，然后点「开始批量研究」。
2. 「背包」解已有的未完成笔记。「无扭曲」和「扭曲」会按类别领取并解已满足前置条件的笔记。自动领取需要背包里有纸和空位。
3. 准备普通笔墨套装和墨囊。墨囊可放在背包、ME 网络或合成格里。补墨优先用附近的 ME 合成终端，找不到时用最近能打开的工作台或匠魂合成站。
4. 「自动使用」默认关闭，解好的笔记会退回背包。开了以后，可自动使用本批解好的笔记。有扭曲的笔记只在「扭曲」模式下自动使用。
